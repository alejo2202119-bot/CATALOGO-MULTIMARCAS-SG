# Catálogo Digital · Inversiones y Comercializadora SG C.A.

Catálogo digital multimarcas de repuestos para motos, con buscador, carrito, modo edición y pedidos por WhatsApp.

- **Empresa:** Inversiones y Comercializadora SG C.A.
- **RIF:** J-40385875-6
- **Portada:** `index.html`
- **Catálogo:** `catalogo.html`

## Publicación

Este repositorio se publica automáticamente en GitHub Pages con cada `push` (ver `.github/workflows/pages.yml`).

## Modo edición

Desde el catálogo, toca el punto (●) al pie de página, ingresa la clave y podrás:
- Cambiar disponibilidad, precio o nombre de un producto tocándolo.
- Agregar productos nuevos (botón "＋ Producto").
- Cambiar la foto de un producto.
- Descargar el catálogo actualizado para volver a subirlo.
